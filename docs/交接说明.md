## 0. 一句话

**显微图像统一视野裁剪工具**：把 OIB / CZI / LIF / TIFF / PNG / JPG / BMP 等显微图读进来，
按同一物理视野（默认 30 µm，1:1 或自由比例）裁成小图，统一加高清标尺、调通道配色、导出 24bit 彩图 +
原始位深数据 + 可选定量统计。**全部本地离线运行，Windows 单机，中文界面。**

## 3. 不变量（改动时不能破坏的设计口径）

1. **统计只读原始位深数据**：`loader.load_stack()`（处理链开着就是链后）；显示区间、屏幕锐化**不参与**统计。
2. **清晰度冻结**：`render.preview_for_view` / `sharpen_display` / `compose` 的参数不许动；
   `tests\sharpness_baseline.py check` 是闸门（±5%）。**换渲染口径要重录基线并备份旧文件 + 写明理由**。
3. **ROI 坐标基准 = 原图整帧归一化（0~1）**，不随缩放/裁剪框变。画布绘制走 `norm_to_view()`，
   不要直接拿整帧坐标当"可见区坐标"用（历史上这么写导致放大后 ROI 画到角落）。
4. **通道黑白点默认 = 该通道数据的实际最小/最大**（2026-09-26 起；老的分位拉伸改成通道 ⋯ 菜单里的可选项）。
   `_auto_ranges()` 必须按 `ch.index`（数据面序号）取区间，**不能按列表位置** —— 有通道被隐藏/合并时位置会错位。
5. **多通道叠加默认加法**（`Settings.merge_mode="add"`，可切 `"max"`=旧的最大强度）；明场通道按灰阶上色。
6. **画布两个"当前屏"量**：`_used_rect` = 当前屏覆盖的整帧归一化范围（裁剪视图里是裁剪框范围）；
   `canvas._pix_um` = 当前预览图覆盖的物理范围。切视图/命中缓存时都要同步，别留旧的（历史上导致四周发黑）。
7. **发布包会删掉** pandas / matplotlib / mpl_toolkits / fonttools / biopython 与 PySide6 的大半
   （见 `F:\ImageCapture_Build\make_release.py` 的 `DROP_PREFIXES`），所以**发布代码不许 import 它们**；
   画图用 QPainter 自绘（线剖面就是这么做的）。
8. 用户参数与工程只在 `config/`；**自检不得写盘**（用 `IMAGECAPTURE_NO_SAVE=1`）。
