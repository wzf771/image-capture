# Image capture 使用说明

显微图像统一视野裁剪工具。把不同物镜、不同分辨率拍的一批图，裁成**相同的物理视野**，
并画上**长度准确的新标尺**，一键导出成 24bit 彩色图。

---

## 一、怎么启动

* 双击桌面上的 **Image capture** 快捷方式（不会弹黑色命令行窗口）。
* 或者双击程序文件夹里的 **`Image capture.exe`**（推荐，双击即开）。

程序自带运行环境，换电脑时把 `E:\ImageCapture` 整个文件夹拷走即可，不用另装 Python。

---

## 二、窗口太小 / 显示不全怎么办

窗口打开时会自动按你屏幕的可用区域定大小（不会再溢出屏幕）。三个办法让画面更宽松：

* 顶栏的 **左栏 / 右栏** 按钮：点一下收起某一栏，中间显示区立刻变大；再点一下放回来。
  收起状态会记住，下次打开还是你上次的样子。
* **每个卡片的标题都可以点**：点一下收起内容（标题前面的箭头会从 ▼ 变成 ▶），
  不用的卡片折起来，剩下的就宽松了。左栏右栏内容多时可以上下滚动。
* 中间显示区是**固定正方形**，永远完整显示整张图（不会变形、不会被裁掉）。
* 中间只有两个按钮：**原图显示** 和 **裁剪结果**。
  * 原图显示：滚轮放大 / 缩小，按住空白处拖动平移，**双击回到整图**。
    放大后画面始终停在图片范围内，不会露白边；缩到最小就是整张图，不会比整张图更小。
  * 裁剪结果：直接看导出后的成品（含标尺），永远是整张、不缩放。

## 二、一次完整流程

1. **导入**：点右上角的 **Get started** 按钮，里面有两个入口——「导入文件夹（含子目录）」和「导入单个/多个文件」；也可以把文件夹直接拖进窗口。
   * `.oib` / `.oif`（奥林巴斯 FV1000）会**直接读出厂标定**（最准），通道、物镜、变倍也一起读出来。
   * `.czi`（蔡司，含 Airyscan）和 `.lif`（徕卡 LAS X，另有 .lof/.xlif/.xlef/.xlcf）同样**直接读文件自带像素尺寸**，
     通道名、物镜型号也会一起显示。多序列的 LIF 会取最大那张，并在提示里写明。
   * `.tif/.tiff/.png/.jpg/.bmp` 先看文件里有没有分辨率信息；没有就靠"标尺识别 + 认字"。
   * 如果还是识别不出来，左栏「对未标定的图自动识别」再跑一次，或者手动填 µm/像素。
2. **分组**：导入后会自动按「像素尺寸 + µm/px」分成若干组，每组是一个独立的方框。
   * 点组 = 中间立刻显示这一组的第一张图；下方「组内图片」可以逐张切换。
   * 需要手动归组时：选中一张图 → 左栏「移动当前图到…」。
3. **定裁剪框**：右栏「裁剪视野」默认 30 × 30 µm（1:1 方框）。
   * 想要别的形状：取消勾选「锁定 1:1 方框」，宽和高分别填；或用 30×30 / 60×30 / 30×60 预设。
   * 中间画布上直接**拖方框**或**拖四个角**；小方框看不清就点「放大到裁剪框」，看完点「适应窗口」。
   * 勾上「组内裁剪框位置一致」：整组共用同一个位置（改一次，全组一致）。
4. **改颜色**：右栏「通道与颜色」里，每个通道可以改颜色、开关、以及黑点/白点。
   * 黑白点只改显示与出图颜色，**不动原始数据**；合图是"灰底 + 各荧光通道按颜色叠加"。
5. **新标尺**：右栏「新标尺」里设置，中间点「裁剪结果」可以马上看到成品样子。
6. **导出**：「一键导出全部」按组批量出图；只想出当前这张用「只导出当前图」。
   出完后点「导出报告 CSV」拿到每张图的标定、裁剪框、输出文件清单。

## 三、标尺能调什么

| 参数 | 说明 |
| --- | --- |
| 加上新标尺 | 关掉就只裁剪、不画标尺 |
| 长度自动取 1/2/5×10ⁿ | 勾上 = 自动挑一个"好看的整值"；取消后手动填 µm |
| 位置 | 右下 / 左下 / 右上 / 左上 |
| 颜色 | 自动（黑底画白、白底画黑）/ 白 / 黑 / 自定义取色 |
| 粗细 | 像素；0 = 按图宽自动 |
| 刻度 | 两端+6 等分（和你现在的图一致）/ 只画两端 / 不画 |
| 显示长度文字 | 关掉就只有线、没有字 |
| 文字带上 µm | 关掉只显示数字（如 `50`） |
| 字体 | **Arial、Arial 粗体、Times New Roman、Times New Roman 粗体、微软雅黑、黑体、宋体** |
| 字号 | 像素；0 = 按图宽自动（大图自动大，小图自动小） |
| 边距 | 距图边多少像素；0 = 自动 |
| 导出放大 | 1× / 2× / 4×：把裁剪结果放大后导出。**标尺是在放大后按最终分辨率重新高清绘制的**，所以图片放大变糊了，标尺依然锐利 |
| 另存一张透明标尺 PNG | 只出标尺、背景透明；丢进 AI / Illustrator 里随便放大也不会糊 |

> 字体说明：这两个字体是 Windows 自带的系统字体，程序只是**调用**它们来画字，
> 不复制、不打包字体文件，所以不涉及版权问题。换电脑只要系统里有这两个字体就能正常出图。

> 标尺清晰度说明：标尺（线、刻度、文字）都是**单独一层、按 4 倍超采样绘制**再合成到图上的，
> 所以它的清晰度**完全不跟随图片**——图片再糊、放得再大，标尺边缘和文字都是干净锐利的。
> 想让标尺随图变大变小，把「粗细」「字号」「边距」都填 0（自动）即可。

## 四、导出规则

* 输出一律 **24bit 彩色**（RGB），不会出现灰度格式的文件。
* 「导出内容」勾几个出几张：
  * 合并彩色图 → `原名_crop.png`
  * CH1 / CH2 / CH3 单独 → `原名_crop_CH1绿.png` 之类（单通道也存成 24bit 彩色）
* 时间序列（如 FRAP）：
  * 只出当前帧（滑到第几帧就出第几帧）
  * 出全部帧（按同一个裁剪框整段导出）
  * 只出指定帧（填 `1,5,12` 或 `1-10`）
* 默认输出到 `E:\ImageCapture\output\组名\`，也可以在「导出内容」里改目录。
* TIFF/PNG 里都写入了分辨率信息（µm/像素），拖进 ImageJ / Fiji 打开就是标定好的图。

## 五、常见问题

**标尺识别不准 / 读不出数字？**
自动识别只在没标定的时候用。真正可靠的是 `.oib` 里的出厂标定，优先用 OIB。
导出图识别不了时，右下「标定」里手动填 µm/像素，点「刷到整组」一次搞定。

**裁剪框太小看不见？**
裁剪 30 µm 的框在 0.621 µm/像素的图上只有 48 像素，是正常的。点「放大到裁剪框」即可。

**原图比裁剪框还小？**
「裁剪视野」下面的「视野不足」可以选：补边 / 跳过 / 收缩。

**想让组内每张各放各的位置？**
取消勾选「组内裁剪框位置一致」，之后每张图各自记自己的裁剪框位置。

**为什么有的图比我以前看着亮？**
第一次打开一张图时，程序会按**数据本身**自动给一套显示区间（黑点/白点）。
不同厂商位数不一样（奥林巴斯 12bit、蔡司常在 16bit 容器里放 13bit 数据），只按位深取白点会普遍偏暗。
不满意就在「通道与颜色」里手动改黑点/白点，或者把两个值改回 0 / 满量程。

**参数会保存吗？**
关窗口或点「保存参数」会存到 `E:\ImageCapture\config\settings.json`，下次打开照旧。

**出问题了？**
日志在 `E:\ImageCapture\logs\app.log`，把它发我即可。

## 六、文件夹里都是什么

```
E:\ImageCapture\
├─ Image capture.exe    启动用（双击即可，推荐）
├─ ImageCapture.vbs     备用启动脚本
├─ app\                  程序本体
│   ├─ main.py           入口
│   ├─ core\             读图 / 标尺 / 合成 / 导出
│   └─ ui\               界面
├─ runtime\python\       自带的 Python 和依赖库
├─ assets\icon.ico       图标（等你给正式图标后替换）
├─ config\               参数配置
├─ cache\thumbs\         缩略图缓存（随便删）
├─ output\               导出的成品图 + 处理报告.csv
├─ logs\app.log          运行日志
└─ tests\                自检脚本（smoke.py / gui_shot.py / preview_bar.py）
```
